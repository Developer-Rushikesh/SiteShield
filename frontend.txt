# FRONTEND DEVELOPMENT PROMPT

## 24/7 Website Monitoring SaaS Dashboard

You are building ONLY the FRONTEND of a professional 24/7 Website Monitoring SaaS application.

Do NOT create the Django backend yet.

The frontend must be completely functional using temporary/mock data so that the entire UI, navigation, dashboard, charts, project management, monitoring pages, history, incidents and notifications can be tested before backend development.

---

# 1. Technology

Use:

* React.js
* Vite
* React Router
* Axios
* Recharts
* JavaScript
* CSS / CSS Modules or a clean styling approach

Do not use Django templates.

Frontend must be completely independent from Django.

---

# 2. Main Goal

Build a professional SaaS dashboard where a user can monitor multiple websites/projects.

The UI should make it extremely easy to understand:

* Which websites are healthy
* Which websites are down
* Which websites are slow
* Website uptime
* Response time
* HTTP status
* Monitoring history
* Incidents
* Notifications
* Alerts
* Project status

The application should look like a real SaaS product suitable for showing to freelance clients.

Do NOT make it look like a basic college CRUD project.

---

# 3. Design Requirements

Design should be:

* Professional
* Clean
* Modern
* Minimal
* Responsive
* Easy to understand
* SaaS dashboard style
* Desktop-first but mobile responsive

IMPORTANT:

Do NOT add unnecessary animations.

Do NOT add:

* Excessive animations
* Particle effects
* Background animations
* 3D effects
* Flashy transitions
* Unnecessary gradients
* Decorative effects that reduce usability

Use subtle hover states and normal UI transitions only where useful.

Focus on:

**Data + usability + clean layout.**
